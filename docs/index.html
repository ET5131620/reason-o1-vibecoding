What it does

A control room for your AI toolbox.

It reads, it explains, it advises. It never installs or runs anything by itself.

Council

Point it at a project. Get what it needs.

It reads the folder (read-only), writes a passport — mission, stack, connections — and ranks the kits, skills, MCPs and CLIs the project needs.

  • What you have and what's missing, side by side.
  • A ready prompt so your own agent can dig deeper — with your account, no API key.

Get started

Two minutes. One command.

01 · RUN

Download and start

Get the ZIP, unzip, double-click ARRANCAR.bat — or clone it below. Standard library only: nothing to install.

02 · SCAN

See your map

A short first-run setup: name (optional), folders, what it may read, the terms, a starter pack and free courses.

03 · BUILD

Ask, pick, ship

Open a kit, ask the Council about a project, or connect it to your agent over MCP.

git clone https://github.com/ET5131620/reason-o1-vibecoding.git
cd reason-o1-vibecoding
python reason_o1.py
# optional: give your agent the map
claude mcp add reason-o1 --scope user -- python /path/to/reason_o1.py mcp

Local first

Your PC. Your data. Your yes.

It only advises. What you install — and its security — stays your call.

  • Runs on 127.0.0.1 only, with a fresh session token on every start.
  • Reads names, counts and dates — never keys, environment variables or conversation content.
  • Never runs downloaded code. You get the commands and a request for your agent, which asks first.
  • Usage reading is off until you turn it on.
