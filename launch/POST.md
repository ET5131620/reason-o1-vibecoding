## 1 · GitHub release notes (v1.0.0)

**REASON O1 / VibeCoding 1.0 — free, open source, runs on your PC**

A living map of your AI ecosystem. It finds every model, agent, skill, MCP server and CLI on your machine and tells you — in plain words — what each project is missing.

What's in 1.0:

- **Inventory** — Claude Code, Codex, Cursor, ChatGPT, Ollama, skills, MCPs, CLIs, local models and git projects, in one constellation map.
- **18 tool kits** — 3 essentials and 7 complete per goal, ranked by GitHub stars, each tool with its why, what it pairs well with, and a visible Get button.
- **Trends** — rising GitHub repos, Hacker News and Reddit, with a preview before you leave the app.
- **Council** — reads a project (read-only), writes its passport and lists what it needs.
- **Usage** — tokens by day, project and model from your local Claude Code and Codex logs; Codex limits; OpenRouter balance; OmniRoute status. Off until you turn it on.
- **Learn** — LLM, MCP, CLI, skill, agent, API and RAG, with animated step-by-step explanations, plus free official courses.
- **MCP server** — your agent gets to know your inventory and kits. No API key.
- **Four languages** — English, Português, Français, Español.
- **Installable app (PWA)** and self-update with backup.

Python 3.10+, standard library only. MIT.

It only advises: it never installs or runs anything by itself. See [TERMS.md](TERMS.md).

REASON O1 is a thank-you to the open source community and a free head start before **REASON ONE**, the agent-driven software engineering studio launching in mid-December as a closed-source product.
